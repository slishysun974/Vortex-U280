# V08 本地第二轮配对实验

每类新题各有 A、B 两个变体。以预定种子 `V08-LOCAL-R2-20261122` 调用原 V08 的分层分配，在六个题对中平衡每组领取 A/B 的次数和先做次数。P/Q 是分配标签。本机负责发题、传递审查意见、封存和检验。每题单独使用空工作目录和新的实现上下文，模型只接收单卡公开材料及组内意见。

两组依次做初稿、审查、定稿。单智能体复用实现上下文自审。双智能体在新上下文审查同一张卡和初稿，再由原实现者定稿。两组都请求 `gpt-6.2-sol / medium / priority`，每席累计 60,000 个 input + output token、45 分钟墙钟和零额外工具费用。允许用 CPython 3.13 标准库写纯函数，模型调用禁用本地工具、联网检索与跨会话记忆。主持程序在本机运行，推理由当前登录的 Codex 模型服务提供。账单和实际服务部署版本无回执时记缺失。

冻结前先用无关文本各测试一次单上下文和双上下文的三轮路径。续接 token 取同一上下文的 CLI 累计量差值，并与本机 Codex 会话日志中的逐请求用量逐项相等。缓存 token 已计入输入，推理 token 已计入输出。发题前核对计量回执和题集清单哈希。单席投递前预留预算，任一轮使实际累计超过上限则 FAIL。计时从首次投递到封存，包含服务等待和意见转交。模型响应结束时才能取得真实用量。

每席最多封存一次。封存后在两个新目录回放仅含私测输入的同一份源码，每次限 30 秒。两次都须退出 0，按用例 ID、类型、顺序和答案精确判分。公开样例也在本地执行并单列。已有提交和失败均保留，外部故障、未开题、预算失败和功能失败分别记录。

主指标为每组 6 个预分配席位中通过独立验收的数量。给出逐对结果、组内总 token、用时与 token 中位数，以及双智能体减单智能体的配对中位数。保留全部实际投递的消耗，另列双方均封存的题对。单轮仅六个题对，报告原始差异及其方向。
