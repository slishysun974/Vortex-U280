# V08 本地单人调度试验

本轮由本地程序代行发题、转交审查意见和封存。题卡、答案、分组和顺序取自冻结的 V08 v1，原清单 SHA-256 为 `436358ed78990df8c83c3acba4fdf7f482bc4980c2714501c4573640e67ce3a7`。P/Q 只保留为原分配标签。本轮统计使用独立版本 `V08-local-v2`。

每席位依次进行初稿、审查、定稿三轮。单智能体复用初稿上下文自审、定稿。双智能体的审查者使用独立上下文，阅读同一张卡和初稿，意见交回原实现者定稿。两组使用同样的公开材料、轮次和截止条件。审查串行，题卡由本地 Codex CLI 交给当前登录的模型服务，推理位置由服务方决定。参与者以文本提交，只看本卡及组内交接；自动调度器从项目外临时目录发起请求，禁用 shell、apps、网页检索和子代理。任何可见工具调用均使席位失效。两组在模型内自查公开样例，提交后由本地 Python 执行公开样例与私测。源文件按定稿原文封存，仅剥离完整的 Markdown 代码围栏。

每个席位沿用 45 分钟、60,000 个 input + output token、零额外工具费用。每次请求使用 `gpt-6.2-sol`、medium、priority，保留请求参数、上下文 ID、原始事件及实际用量。计时从初稿投递到文件封存。每轮预留至少 18,000 token，根据上一轮输入和待转发文本增加预留。供应方只在调用完成后返回用量，超过总额记 FAIL。缓存和推理 token 按供应方已有包含关系汇总。模型等待和调度耗时计入墙钟，费用与服务端实际部署标识只在有回执时填写。

按冻结顺序运行六对。一个已投递的席位只有一次提交。系统故障保留原始输出，试次记录区分未开始、外部阻塞、预算失败和功能失败。评分程序在一对均结束后，从同一封存哈希在两个新目录执行冻结 runner，再用 v1 独立评分。两个重放各限 30 秒，保留完整输入之外的评分端答案隔离。总表按每组 6 个预分配席位列出覆盖率、功能结果、时间及 token，另列已配齐的逐对数据。
