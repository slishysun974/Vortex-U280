# V08 本地第三轮配对实验

每席 45 分钟、60,000 个 input + output token、零额外工具费用。请求 `gpt-6.2-sol / medium / priority`。单智能体在同一上下文初稿、自审和定稿。双智能体由独立上下文审查初稿，再交回实现者定稿。两组用同一 CLI 参数、公开材料范围和时间口径。本机发放、封存并运行 CPython 3.13.13 盲测，推理通过当前登录的 Codex 模型服务。仅投递当前卡片和组内材料。

按原 V08 的分层方法以种子 `V08-LOCAL-R3-20261122` 分配，平衡变体与先做次数。六对合成题取自 V03 至 V07 的实际工作边界，覆盖 P0 执行、参数布局与版本校验、队列隔离、RTL/SimX 追踪、AXI DMA 及 MPM 配对验收。变体的具体简化规则由卡片给出。题目以纯函数实现并在本地执行。

先用中性三轮路径校验逐请求用量与日志中 WebSocket 连接标记，再冻结卡片、答案、分配、判分入口及 CLI 计量/等待解析源码。每席仅封存一次。在两个新目录分别执行同一封存哈希和同一隐藏输入，两次各限 30 秒。每项比对类型、顺序和值。两次都通过才作功能接收。两组分母均固定为 6，另外列封存数、失败、阻塞及未运行。记录全体实际观察的墙钟和 token，以及双方均封存的配对差。

主墙钟从发题到封存，含 CLI 启动、网络、模型、转交和重试。单列逐调用的 CLI 启动到 turn 开始、WebSocket 握手、CLI 日志明示的计划重试退避秒数，以及可配对的重试告警到下一次连接开始。握手只用同一日志中的起止配对，退避与告警到重连的区间可重叠。无法配对的连接或重试段记缺失，超时或连接告警数单列。CLI 调用与主墙钟均保留完整值。
