## 一、超时或设备故障后，哪些证据允许释放旧内存？

命令处理器通过 `m_axi_host` 访问 HOST 命令队列及 DMA 暂存区，用户缓冲区位于 HBM。事件等待超时后主机可以先行返回。已有队列 barrier、KDS 空闲和正常打开设备时的 `AP_IDLE` 读数只覆盖各自的观测点。目前项目 runtime 在物理恢复时返回 `E_UNAVAILABLE`，保留故障上下文持有的资源。我们需要明确**旧请求既无法再写原 HOST 页，也无法写入已经复用的 HBM 地址**的可观测时点。[HOST 数据通路](AB_D13_PROGRESS.md) · [事件、队列与复位行为](AB_RECOVERY_LIMITS.md) · [运行时约定](COLLABORATION_PROTOCOL.md)

1. **作用范围。** 对“主机等待到期但设备仍可响应”和“CP 或链路失去响应”两种情况，平台分别支持何种停止、排空或隔离流程？请给出适用版本、操作接口或运维规程、执行权限，以及影响范围（单个上下文、计算单元、PCIe 功能、整卡或其他用户）。
2. **事务与映射。** 从阻止新请求起，命令环中未执行的命令、设备侧在途读写、已发出的 PCIe 写及 HOST 映射分别由谁处理？什么条件满足后可以依次撤销映射、释放 HOST 缓冲区、复用 HBM 地址？若调用进程已退出，哪些保证仍然有效，谁负责收尾？
3. **可观察完成条件。** 请给出可读取的状态字段、日志或运维回执、采样顺序及成功值，并说明它们分别证明哪个环节完成。若平台可保证隔离但设备仍不可计算，请给出释放旧资源和重新开放提交各自需要的证据。
4. **失败与时间界限。** 等待上限如何确定？超时、部分完成、重复请求或状态不可读时，哪些资源继续保留，由谁接管？如需独占窗口，请说明影响的设备范围和恢复服务后的复查条件。

收到答复后，B/C 将按版本核对规程、覆盖的事务和完成条件，再设计隔离窗口的实测。实测会检查失败或部分完成时的资源保留、晚到写入，以及成功后旧句柄失效、重新分配和重跑的结果。没有适用机制或可观察条件时，项目将旧 DMA 隔离依据记为 `BLOCKED`。[恢复验收约定](RUNTIME_RECOVERY_20261111.md)

## 二、TIMING-7 对这两个时钟域如何处置？

两份 DCP 均报告正向 `io_clk_pcie_00_clk_p`（100 MHz）到 `dma_ip_axi_aclk_1`（250 MHz），交互项为 `No Common Node / Partial False Path (unsafe)`。正向 26 个端点中，21 个检查 recovery/removal，5 个被既有例外忽略。recovery 最小余量为 +0.185 ns，removal 为 +0.415 ns。反向 9 个端点均为既有 false path。正向 `report_cdc` 另列 13 条 `CDC-7`、2 条 `CDC-10`。复位 LUT 输入为 `sys_rst_n_sbr` 和 `dest_arst`，其 31 个扇出终点中有 21 个处于 DMA 用户时钟域。[专项复核](AB_D13_PROGRESS.md#2026-11-10-2102-两套专项报告已回传) · [时序报告附件（10 份）（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-2a0f4f4a4267)

1. **时钟关系。** 在上电启动、复位释放、PCIe 链路恢复时，PCIe 参考时钟与经 GT TXOUTCLK、BUFG_GT 导出的用户时钟各何时有效？在哪些模式能保证相位关系？如依赖该关系，请给出对应的约束与模式依据。
2. **正向复位。** 请说明复位经 LUT 到达 PCIe debug 寄存器 CLR 时，如何保证在目的域安全释放。对于 `user_lnk_up_reg/CLR` 以及 `sys_or_hot_rst_uclk_inst`、`user_lnk_up_cdc` 的同步器输入，请一并说明组合逻辑与既有例外的依据。若特定逻辑在该模式被禁用或隔离，请给出对应配置位、网表或设计说明。
3. **反向同步与最终处置。** 反向路径包括 `cur_speed`、`negotiated_width` 和 `sys_rst_sbr`。请确认 XPM 第一级的例外范围、多位状态的采样前提和复位脉冲的使用条件。贵方建议将此告警按现有设计接收、限制运行模式，还是修订平台？如属已知项，请附对应 shell、PCIe IP 与工具版本的工单、发布说明或维护者结论，写明适用条件。

A/B 将据回复记录具体端点、运行模式及处置依据。若依据只涵盖部分端点或模式，其余部分继续记为 `OPEN`。[双向 CDC 与复位扇出对照清单（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-aa889d6d5f03)
