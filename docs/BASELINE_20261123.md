## 在普通电脑上离线复核

使用 Python 3.10 或更高版本。首次下载可按标签取得这次基线。已经在基线目录的读者只需执行最后一行。校验器只读取归档数据，可重复执行。

```sh
git clone --branch baseline-2026-11-23 --depth 1 https://github.com/slishysun974/Vortex-U280.git
cd Vortex-U280
python -B scripts/review_baseline.py
```

返回 `"status": "PASS"` 且退出码为 0 时，可看到四个后端各 48 个历史用例通过。校验器还会比对 Iris 的源码及两份设备镜像、冻结输入、保存的完整输出与保护区，从 3,376 次计数器读取重算 422 次历史启动中的 180 对正式计时，并重新生成六档 CPU／U280 统计和五折结果。V03 和三算子 v1.3/v1.4 的接收范围由上表各自的回执记录。Python 运行器自测可单独执行。[校验实现](../scripts/review_baseline.py) · [基线校验回执](../results/baseline-closeout-20261123-v1/check.json) · [运行器与上手步骤](../README.md#快速上手)

## 后续实验怎样引用

比较前端时沿用同一输入、输出布局和板用配置，分别报告设备周期、退休 warp 指令和主机耗时。根目标锁的历史状态、完整工具链与 D10/D12 二进制的保管位置见发布说明。能力范围以 P0 规范和各实验的固定语料为准。Iris 他人复现与具名签收、物理故障恢复和平台时序专项暂缓，实卡逐 lane 访存属于尚未直接观测的指标。AI 协作部分保留三轮本地对照，原双人操作实验按 `NOT_RUN` 归档。[P0 兼容范围](PTX_COMPATIBILITY_PROFILE.md) · [公开材料范围](PUBLICATION.md) · [三轮协作研究](PROJECT_OVERVIEW.md#已取得的成果)
