## 题集与盲测

第三轮以 Vortex-U280 的编译、运行时和设备接收边界为题源。各题要求同时实现正常路径、边界处理和诊断规则。题卡描述的是合成程序和设备记录，发放、封存和判分在本机执行，推理由已登录的 Codex 模型服务提供。[冻结协议](../experiments/ai-paired-local-round3/protocol.md) · [冻结回执与项目依据哈希（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-328e9fef8fec)

| 题对 | 任务 | 隐藏验收覆盖 |
|---|---|---|
| T1 | P0 PTX 谓词执行见证 | 先判谓词、寄存器未定义、64 位地址、lane 内写后读 |
| T2 | 目标锁与启动参数打包 | 诊断优先级、句柄代次、范围与写别名、对齐和小端 payload |
| T3 | 命令队列退休 | 乱序完成、连续回收、槽位环回、故障锁存与代次隔离 |
| T4 | 逐 lane LSU 追踪重建 | 槽位复用、warp rank、掩码顺序、尾部 lane、完整地址和时序 |
| T5 | DMA 与 AXI 写事务规划 | 窗口映射、4 KiB 边界、未对齐字节写掩码和失败原子性 |
| T6 | MPM 配对计数验收 | 高低位一致快照、空闲检查、64 位差值、镜像绑定和顺序 |

先用无关文本跑两种三轮模式，六次逐调用用量与 CLI 累计值作差逐项相等，六次都有成对的 WebSocket 起止记录。随后对 12 个公开样例、192 个私测输出做参考路径交叉核对。首个准备目录的判分正对照遇到 Python 元组与 JSON 数组的比较差异，runner 退出 1。改为从序列化后的私测材料构建对照，再在新目录冻结。正对照退出 0，人为改错的负对照退出 1。正式发题发生在第二份冻结回执后。[计量预检（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-99d24932f5e9) · [首次对照退出记录（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-32a5b6d5e604) · [最终冻结（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-328e9fef8fec)

两组各六席，变体和先做次数平衡。所有席位沿用每席 45 分钟、60,000 个 input + output token 和 `gpt-6.2-sol / medium / priority`。单组在原上下文自审，双组在独立上下文串行审查，然后回到原实现会话定稿。每席只投递当前公开卡，收到定稿后记录源码 SHA-256。封存后分别在两个新目录用 CPython 3.13.13 重放隐藏输入，每次限 30 秒。[发放顺序与预算（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-47c77106ca72) · [单卡工具（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-d2e0403faa26)

## CLI 计时口径

主墙钟包含所有启动、模型服务、转交和重试时间。CLI 进程启动到 `turn.started` 包含客户端初始化。WebSocket 握手采用日志中对应的连接开始和完成时间戳。重试单列 CLI 声明的计划退避秒数，以及有日志证据时从重试告警到下一次连接开始的实际间隔。两种重试量可能覆盖同一时间段。缺少起止配对的连接只记一次未配对，连接告警单计。合成对照验证了两个完整握手、一次退避和重连间隔，以及一个缺结束标记的握手。[计时对照（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-a48654a2d5c2) · [CLI 计时实现（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-9e9fd22b4fb9)
