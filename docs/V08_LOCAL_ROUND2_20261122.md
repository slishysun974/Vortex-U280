## 多轮计量与题集冻结

先在两个无关文本试次上各发三次请求。单智能体使用一个上下文，双智能体的第二轮使用独立审查上下文，第三轮返回原实现会话。逐轮以同一上下文的 CLI 累计量作差，并与 Codex 日志中的逐调用用量核对。六轮全部匹配。直接相加累计值会把单组的 37,533 token 算成 75,016，双组的 37,489 算成 49,976。两种误差都被检出。中性探针的 token 不计入正式席位。[计量命令与原始回执（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-810ca05887ff)

计量通过后冻结六对新题。每对的 A/B 使用相同的输入结构和相关边界，变化见下表。12 个公开样例和 144 个私测均由两套参考计算核对。判分正对照退出 0，改错对照退出 1。已将题卡、私测、判分入口和分配顺序写入带 SHA-256 的冻结回执。[冻结回执（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-e51b4e26840c) · [题集参考实现（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-6f4b6061748c)

| 题对 | 任务 | A/B 变化 |
|---|---|---|
| T1 | 对齐区间分配 | 低地址起点对齐 / 高地址终点对齐 |
| T2 | 依赖任务派发 | 同时就绪时按 ID 升序 / 降序 |
| T3 | 条带请求拆分 | 银行顺序正向 / 反向，长度按比例放大 |
| T4 | 计数器回绕 | 递增 / 递减 |
| T5 | 写回缓存 | 命中刷新顺序 / 保留插入顺序 |
| T6 | 分支指令放宽 | 短、长指令宽度与短位移边界成对变化 |

每组 6 个席位，每组各有 3 个 A 变体、3 个 B 变体和 3 个先做席位。两组均使用初稿、审查、定稿三轮，预算为每席 45 分钟和 60,000 个 input + output token。双智能体的审查串行执行。请求参数为 `gpt-6.2-sol / medium / priority`。本机负责发放、封存和 CPython 3.13.13 重放，推理由已登录的 Codex 模型服务提供。[冻结协议](../experiments/ai-paired-local-round2/protocol.md) · [发放回执（本地归档）](LOCAL_ARCHIVE_INDEX.md#archive-9dcfb88b3567)
